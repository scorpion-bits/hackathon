# Templates

| Arquivo | Quando usar |
|---|---|
| `task.md` | Nova tarefa detalhada em `planning/tasks.md` |
| `agent-delegation.md` | Ao delegar trabalho a um agente |
| `handoff.md` | Ao finalizar qualquer tarefa (agente ou humano) |
| `decision.md` | Decisão relevante → `docs/06-decisions.md` |
| `decision-request.md` | Pedido de decisão à equipe (👥) — copiar para o Hub |
| `solution-candidate.md` | Cada solução candidata na ideação |
| `blocked.md` | Tarefa bloqueada |
| `scope-change.md` | Nova ideia durante o hackathon |
| `checkpoint.md` | Relatório de checkpoint para a equipe |
